# 庭院微光 · 桌面条 Demo

一个放在屏幕底部、会自己生长的小庭院。工作它长大，偶尔抬头看一眼。

- `index.html`：说明页，内嵌游戏
- `game.html`：游戏本体（单文件，无外部依赖）

## 本地试玩

直接双击 `index.html` 即可（无需服务器、无需联网）。

## 发布到 GitHub Pages

1. 在 GitHub 上新建一个 **Public** 仓库，例如 `courtyard-strip`；
2. 把本目录下的 `index.html`、`game.html` 上传到仓库根目录；
3. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`，保存；
4. 一两分钟后访问 `https://<你的用户名>.github.io/courtyard-strip/`。

## 这是什么

《庭院微光》桌面版的 3 天切片，用来验证一个假设：
**把一座会自己长的庭院放在屏幕底部，30 分钟后你会不会主动想去看它一眼。**

当前包含：6 个种植槽、4 类设施、昼夜与四季、访客、手写信、离线收益。

它不是完整游戏：没有剧情、没有成就、没有多存档，也不代表最终品质。
